# StreamPlay - Twitch VOD Player

## 🎮 Overview

This repo allo you to play any twitch vod on a web player. You can play **any** twitch vod, sub only too, even if you're not sub.

## 🚀 Installation

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or newer)

### Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/Hrodvitnir-Fenrir/Twitch_Vod_Player.git
   cd streamplay
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the application:
   ```bash
   npm run start
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

### Basic Usage

1. Find a Twitch VOD you want to watch
2. Right-click on one of the storyboard thumbnails and copy the **image address**
3. Paste the link into StreamPlay
4. Click "Transform and Play"

## ⌨️ Keyboard Shortcuts

When watching a video, you can use these keyboard shortcuts:

| Key | Function |
|-----|----------|
| ← | Rewind 30 seconds |
| → | Forward 30 seconds |
| ↑ | Increase volume |
| ↓ | Decrease volume |
| Space | Play/Pause |
| F | Toggle fullscreen |
| M | Toggle mute |
